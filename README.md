# SAN-IN HIDDEN JAPAN

Static prototype site prepared for GitHub Pages.

## GitHub Pages
1. Upload the contents of this folder to the repository root. `index.html` must stay at the root.
2. GitHub: Settings -> Pages.
3. Source: Deploy from a branch.
4. Branch: `main`, folder: `/ (root)`.
5. Save.

The site uses relative links, so the existing page and asset structure should work on a GitHub Pages project URL.
